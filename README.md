# Renting Assistance Service

面向租房通勤决策的地图服务。用户选择公司、学校等目的地并设置出发时间和通勤预算后，系统计算公共交通可达站点、边界站点和可达区域，后续再结合住宅小区与房源信息提供筛选和排序。

## 当前状态

项目已完成 M1 地图基础能力，并实现 M2 的第一版可达性闭环。当前 Web 应用使用高德 JS API 和 Web 服务 API，可搜索工作地点、查询附近公共交通，并按日期、时间和预算同时扫描双向候选站点，输出去公司与回住处两个方向的最远可达站点。

## 计划中的主要能力

- 地点搜索、地理编码和地图选点
- 附近公交、地铁、电车等站点查询
- 站点线路、方向和运营信息展示
- 基于出发时间与通勤预算计算公共交通可达范围
- 展示最远站点、各方向边界站点和最佳路线
- 在可达站点附近搜索住宅小区并进行通勤评分

## 技术方向

- Web：Next.js + React + TypeScript
- API：Node.js + TypeScript（框架在初始化阶段确定）
- Worker：异步执行批量路线和可达性计算
- 数据：PostgreSQL/PostGIS + Redis
- 工程：pnpm workspace + Docker

技术栈可在接入地图 API 前调整；领域模型和地图适配接口不依赖具体供应商。

## 本地运行

高德配置保存在项目根目录的 `.env.local`。启动当前 Web 应用：

```powershell
cd apps/web
npm install
npm run dev
```

开发地址默认为 `http://localhost:3000/`。

当前 Web 版本已实现高德地图加载、地点输入提示、地图定位、通勤条件设置、500 米/1 公里/1.5 公里三档公共交通站点查询、途经线路展示，以及基于真实线路站序的双向公共交通可达性计算。计算前可选择最多 3 个公司侧接驳站点，并可限定具体公交或轨道线路。系统先通过高德步行规划取得“地点 ⇄ 接驳站”的时间 1，再用总预算减去时间 1 得到每个站点的公共交通预算时间 2；候选站来自接驳站途经线路的完整站序，并由公共交通路径规划逐个复核。当前算法是配额可控的直达线路抽样，不是完整换乘网络或连续等时圈。
