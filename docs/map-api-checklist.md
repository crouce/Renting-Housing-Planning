# 地图 API 接入清单

提供地图 API 时，请尽量附上以下信息。缺失的能力不一定阻塞开发，但会影响可达性算法选择。

## 必需能力

- [ ] Web 地图 SDK 或可嵌入地图组件
- [ ] 地点关键词建议
- [ ] 地理编码与地点详情
- [ ] 附近公共交通站点搜索
- [ ] 公交、地铁、电车等公共交通路径规划
- [ ] 可指定出发日期与时间
- [ ] 路线结果包含步行、等待、乘车、换乘和总耗时

## 强烈建议

- [ ] 一个起点到多个终点的公共交通矩阵
- [ ] 公共交通等时圈或可达范围
- [ ] 站点关联线路、方向和完整站序
- [ ] 首末班时间、班次或时刻表
- [ ] 最大步行距离、最大换乘和交通方式限制
- [ ] 路线距离以及各段明细

## 可选增强

- [ ] 实时到站
- [ ] 临时停运和服务告警
- [ ] 无障碍路线信息
- [ ] 住宅小区或社区 POI 分类
- [ ] 步行路径矩阵

## 平台与合规信息

- API 文档地址和 SDK 版本
- 使用平台：Web、服务端、移动端或小程序
- Key 类型及域名、IP、签名限制
- QPS、每日配额、计费方式和超额行为
- 数据缓存期限、持久化和二次展示限制
- 服务覆盖国家、城市和公共交通类型
- 坐标系：WGS-84、GCJ-02、BD-09 或其他
- 时区、日期格式和历史/未来出发时间限制

## 建议提供的验证样例

选择一个熟悉的公司地点，并提供：

- 地点名称和准确地址
- 一个工作日早高峰出发时间
- 期望通勤预算，例如 45 分钟
- 一至两个已知可达站点
- 一个已知不可达或明显超过预算的站点

这些样例将作为地图适配器和可达性计算的首批验收用例。
